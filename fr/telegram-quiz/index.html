FAQ

FAQ sur les quiz Telegram

Comment créer un quiz sur Telegram ?

Ouvrez TgDraw, ajoutez les questions et les bonnes réponses, attribuez des points, configurez la publication et choisissez la fin : sans gagnant, avec code promo ou avec tirage au sort.

Quelles fins sont disponibles ?

Vous pouvez afficher un résultat sans désigner de gagnant, révéler un code promo ou utiliser le système intégré pour choisir un gagnant au hasard.

Comment fonctionne le tirage au sort intégré ?

TgDraw crée une liste de participants selon vos conditions et choisit un gagnant au hasard. La liste peut inclure tous ceux qui ont terminé le quiz ou uniquement ceux qui ont obtenu le score requis.

Puis-je réserver le quiz aux abonnés ?

Oui. Ajoutez les chaînes Telegram obligatoires et le bot vérifiera chaque abonnement avant le début du quiz.

Puis-je utiliser un code promo sans choisir de gagnant ?

Oui. Selon la fin choisie, les participants peuvent voir un code promo après le quiz sans qu’aucun gagnant soit sélectionné.

Quels résultats sont disponibles après le quiz ?

Vous pouvez consulter les réponses et les scores et, lorsque l’export est disponible, enregistrer les données des participants, les statistiques des questions et les informations sur le résultat ou le gagnant.
