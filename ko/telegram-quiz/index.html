결과와 보상

퀴즈 종료 방식은 직접 선택

당첨자를 고르지 않고 끝내거나, 프로모 코드를 보여주거나, 내장 기능으로 무작위 추첨을 진행할 수 있습니다. 퀴즈 설정 단계에서 원하는 결과 방식을 선택합니다.

비주얼 설정

프로젝트에 자연스럽게 어울리는 퀴즈

WebApp 테마를 채널, 브랜드, 강의 또는 캠페인에 맞춰 퀴즈가 Telegram 프로젝트의 자연스러운 일부처럼 보이게 하세요.

퀴즈 구성

목표에 맞는 문제, 채점, 결과 방식

TgDraw는 문제, 정답, 점수, 참여 조건을 하나의 WebApp 퀴즈에 담습니다. 학습, 구독자 참여, 브랜드 게임, 프로모션 캠페인에 활용할 수 있습니다.

채널에서 게임 공개

Telegram 채널이나 그룹에 퀴즈를 게시하세요. 참가자는 메신저를 나가지 않고 WebApp을 열어 바로 시작할 수 있습니다.

정답과 자동 채점

정답을 표시하고 문제마다 점수를 지정하세요. TgDraw가 참가자별 최종 점수를 자동으로 계산합니다.

구독자 전용 참여

필수 채널을 추가하면 TgDraw가 퀴즈 시작 전에 구독 여부를 확인하고 조건을 충족한 참가자만 참여시킵니다.

세 가지 종료 방식

당첨자 없이 종료하거나, 프로모 코드를 공개하거나, 조건을 충족한 참가자 중에서 무작위로 당첨자를 선택할 수 있습니다.

내 스타일의 WebApp

브랜드나 게임 콘셉트에 맞는 테마를 선택해 퀴즈가 Telegram 프로젝트에 자연스럽게 어울리도록 하세요.

내보낼 수 있는 결과

답변, 점수, 참가자 데이터를 확인하세요. 내보내기를 사용하면 결과 검증, 당첨자 정보 저장, 어려웠던 문제 분석이 쉬워집니다.

퀴즈 활용 방식

목표에 맞춰 게임 구성

구독자 대상 짧은 챌린지, 학습 평가, 프로모 코드 게임, 무작위 추첨이 포함된 경품 퀴즈를 만들 수 있습니다.

01

정답 하나 선택

하나의 정답을 고르는 기본 문제 형식입니다.

02

복수 정답 선택

정답이 여러 개인 문제에 사용합니다.

03

직접 입력하는 답변

선택지를 제공하지 않고 용어, 이름, 짧은 답변을 입력받을 수 있습니다.

04

유연한 점수 설정

문제마다 다른 점수를 부여하고 최종 점수로 참가자를 비교할 수 있습니다.

05

당첨자 없는 결과

경쟁이나 경품이 필요하지 않다면 마지막 문제 뒤에 점수, 해설 또는 마무리 메시지를 보여줄 수 있습니다.

06

프로모 코드 또는 무작위 추첨

완료 후 프로모 코드를 공개하거나 조건을 충족한 참가자 중에서 당첨자를 무작위로 선택하세요.

시작 방법

Telegram 퀴즈를 만드는 4단계

Telegram 퀴즈를 만들려면 먼저 문제와 정답을 준비한 뒤 점수, 참여 조건, 종료 방식을 설정하세요. 종료 방식은 당첨자 없음, 프로모 코드, 무작위 추첨 중에서 선택할 수 있습니다.

01

퀴즈 목표 정하기

주제, 대상, 문제 수를 정하고 참가자가 완료 후 무엇을 보거나 받을지 결정하세요.

02

문제와 정답 설정

답변 선택지를 추가하고 정답을 표시한 뒤 문제마다 점수를 지정하세요.

03

게시 위치와 참여 조건 설정

채널이나 그룹을 선택하고 필요하면 필수 구독을 추가한 뒤 게시 전에 퀴즈를 미리 확인하세요.

04

종료 방식 선택

퀴즈를 게시한 뒤 당첨자 없이 끝내거나, 프로모 코드를 공개하거나, 무작위 추첨을 실행하세요. 답변과 점수는 내보내기 파일에 저장할 수 있습니다.

참가자 경험

긴 양식이 아니라 게임처럼 참여

문제가 한 번에 하나씩 나타나 참가자가 챌린지에 집중할 수 있습니다. 진행률로 남은 분량을 확인하고, 마지막 화면에서 결과, 프로모 코드 또는 추첨 안내를 볼 수 있습니다.

한 번에 한 문제

긴 입력 항목과 선택지가 한꺼번에 보이는 대신 문제를 단계별로 풀어갑니다.

명확한 마무리

참가자는 결과를 확인하고, 프로모 코드를 받거나, 무작위 당첨자 추첨 대상이 되었음을 바로 알 수 있습니다.

FAQ

Telegram 퀴즈 FAQ

Telegram에서 퀴즈를 어떻게 만드나요?

TgDraw를 열고 문제와 정답을 추가한 뒤 점수를 지정하세요. 게시 방식을 설정하고 당첨자 없음, 프로모 코드, 무작위 추첨 중에서 결과를 선택합니다.

어떤 종료 방식을 사용할 수 있나요?

일반 결과만 보여주고 당첨자를 선택하지 않거나, 프로모 코드를 공개하거나, 내장 무작위 추첨으로 당첨자를 선택할 수 있습니다.

내장 무작위 추첨은 어떻게 작동하나요?

TgDraw가 설정 조건에 따라 참가자 목록을 만든 뒤 그중 한 명을 무작위로 선택합니다. 퀴즈를 완료한 모든 사람 또는 기준 점수를 달성한 사람만 포함할 수 있습니다.

구독자만 퀴즈에 참여하게 할 수 있나요?

네. 필수 Telegram 채널을 추가하면 봇이 퀴즈 시작 전에 각 참가자의 구독 상태를 확인합니다.

당첨자 대신 프로모 코드를 제공할 수 있나요?

네. 당첨자를 선택하지 않고도 퀴즈 완료 후 참가자에게 프로모 코드를 보여줄 수 있습니다.

퀴즈 후 어떤 결과를 확인할 수 있나요?

답변과 점수를 확인할 수 있으며, 내보내기를 사용할 수 있을 때는 참가자 데이터, 문제 통계, 결과 또는 당첨자 정보도 저장할 수 있습니다.
